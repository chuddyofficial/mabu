    MABU
    Intelligence Research Platform

    Case management and link analysis for open-source research.

    Document findings, connect identifiers across cases, and produce reports, all on infrastructure you control.

    • Encrypted case vaultEvery case is stored encrypted at rest (Fernet: AES-128 + HMAC).
    • Cross-case link analysisSurfaces shared emails, handles, IPs, phones and names between cases.
    • Accountable by designRole-based access with a full audit trail of every action.

    This system is for authorized use only. Sign-ins and actions are recorded in the audit log. Use MABU only for information you have lawful, legitimate access to.

    Sign in

    Use the account issued to you by your MABU administrator.

    No accounts exist yet. Run python setup.py on the server to create the first administrator.
    Sessions expire after 12 hours. Repeated failed sign-ins are rate-limited.

    Snowflake structure
    
              
    A 64-bit integer encoding a timestamp and internal identifiers, relative to the Discord epoch (2015-01-01 00:00:00 UTC).
    
              
    Bit layout (64 bits)

 63                                22 21    17 16    12 11         0
| timestamp (42 bits, ms since epoch) | worker | process | increment |

DISCORD_EPOCH = 1420070400000   // unix ms

timestamp  = (snowflake >> 22) + DISCORD_EPOCH
worker_id  = (snowflake & 0x3E0000) >> 17
process_id = (snowflake & 0x1F000)  >> 12
increment  =  snowflake & 0xFFF
    
            
    

            
    
              
    Batch decode
    Local only
    
              
    Decode several snowflakes at once (user, message, server or channel IDs) to order observations on a timeline or compare account ages. One ID per line.

    Live handle check
    Public infrastructure
    
              
    Requests each platform's own profile endpoint and inspects the actual response, not just the status code, to judge whether a profile exists. No third-party aggregators are used. Platforms that return the same page to automated requests whether or not an account exists (Instagram, TikTok, Twitch, Telegram) are deliberately excluded. "Inconclusive" means the response couldn't be classified with confidence, for example because of rate limiting; it does not mean "no".
